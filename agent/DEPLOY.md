# Инструкция по деплою агента Home Monitor (hsagent) на домашний сервер (Ubuntu)

Данная инструкция описывает процесс ручного обновления и деплоя новой версии сервиса `hsagent` на домашний сервер под управлением Ubuntu Linux.

## Предварительные требования

1. Доступ к серверу по SSH.
2. Права `sudo` (или доступ под пользователем `root`).
3. Ссобранный исполняемый файл агента (`agent_bin`) под архитектуру Linux (обычно `amd64`).

---

## Шаг 1. Подключение к серверу по SSH

Подключитесь к вашему домашнему серверу:

```bash
ssh username@your_server_ip
```
*(При необходимости переключитесь на пользователя с правами суперпользователя или используйте `sudo` для сервисных команд).*

---

## Шаг 2. Остановка старой версии сервиса

Перед заменой бинарного файла необходимо остановить работающую системную службу:

```bash
sudo systemctl stop hsagent
```

Убедитесь, что служба успешно остановлена:
```bash
sudo systemctl status hsagent
```
*(Статус должен показывать `inactive (dead)`).*

---

## Шаг 3. Замена файлов (бинарник и конфигурация)

Обычно рабочая директория сервиса на сервере — `/root/homemonitor` (согласно systemd unit-файлу).

1. Перейдите в рабочую директорию сервиса:
   ```bash
   cd /root/homemonitor
   ```

2. Загрузите новый бинарный файл `agent_bin` на сервер (например, через `scp` с вашей машины или `sftp`).
   *Пример команды с локальной машины:*
   ```bash
   scp agent_bin username@your_server_ip:/root/homemonitor/agent_bin
   ```

3. Убедитесь, что файл имеет права на выполнение:
   ```bash
   chmod +x /root/homemonitor/agent_bin
   ```

4. *(Опционально)* Если изменился конфигурационный файл `config.toml`, обновите его в той же директории `/root/homemonitor/config.toml`.

---

## Шаг 4. Обновление Systemd Unit-файла (при необходимости)

Если в репозитории изменился файл службы `hsagent.service`:

1. Скопируйте свежий unit-файл в системную директорию:
   ```bash
   sudo cp hsagent.service /etc/systemd/system/hsagent.service
   ```
2. Перезагрузите конфигурацию systemd, чтобы подхватить изменения:
   ```bash
   sudo systemctl daemon-reload
   ```

---

## Шаг 5. Запуск нового сервиса

Запустите обновленную службу:

```bash
sudo systemctl start hsagent
```

Включите автозапуск службы при загрузке системы (если еще не включен):
```bash
sudo systemctl enable hsagent
```

---

## Шаг 6. Проверка работоспособности

1. Проверьте текущий статус службы:
   ```bash
   sudo systemctl status hsagent
   ```
   *Статус должен быть `active (running)`.*

2. Проверьте логи сервиса на наличие ошибок и успешный запуск:
   ```bash
   sudo journalctl -u hsagent -f -n 100
   ```
   *Убедитесь, что агент успешно подключается к сети, слушает порт и не падает в цикле рестарта.*
